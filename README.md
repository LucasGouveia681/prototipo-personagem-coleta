## Sobre o projeto 
o projeto personagem coleta nele você tem que coletar as frutinhas pelo mapa com o personagem
 
## O que o projeto faz 
- o jogador movimenta a bolinha com as setas/WASD
- ao encostar nos itens, eles somem e o placar aumenta
- quando coleta tudo, aparece a mensagem de vitória
 
## O que o projeto contém 
- **Scripts:**
- PlayerController – movimenta o jogador e consiga coletar as frutas - CameraController - faz com que a câmera siga o personagem 
- **Objetos principais:** ex: Player, Mapa, PickUp
- **Recursos usados:** Rigidbody, Box Collider, TextMeshPro, camera controller
 
## Controles 
- WASD/SETAS – faz com que você consiga se movimentar
